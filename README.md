# Zecpath AI

Zecpath AI is the AI system for the Zecpath autonomous hiring platform.

## Project Structure

- `data/` - Sample and input data
- `parsers/` - Resume and document parsing
- `ats_engine/` - AI resume screening and ranking
- `screening_ai/` - AI candidate screening
- `interview_ai/` - AI interview processing
- `scoring/` - Candidate scoring and evaluation
- `utils/` - Common utilities and logging
- `tests/` - Automated tests
- `logs/` - AI system logs
